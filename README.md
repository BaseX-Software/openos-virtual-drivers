# OpenOS Virtual Drivers

Virtual mouse + keyboard drivers for OpenOS by BaseX Softwares.

The OS sees real input devices. Not injected input.

## Download

| Platform | Architecture | File |
|----------|-------------|------|
| Linux | x64 | `openos-driver-linux-x64` |
| Windows | x64 | `openos-driver-windows-x64.exe` |
| macOS | ARM64 | `openos-driver-macos-arm64` |

## Installation

These drivers are installed automatically by the OpenOS application on first launch.
No manual installation required.

## What it does

The driver registers virtual input devices with the operating system:
- **Virtual Mouse** — move, click, scroll, drag
- **Virtual Keyboard** — type, keypress, shortcuts

The OS cannot distinguish these from real hardware input devices.
